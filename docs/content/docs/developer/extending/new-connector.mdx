This guide covers implementing a new database connector in the `connection/` package.

## Overview

A connector consists of four classes plus a factory registration:
1. **AuthenticationModule** — manages connection pool and credentials
2. **ConnectionModule** — executes queries and tests connections
3. **RecordParser** — transforms raw results into NeoBoard's format
4. **SchemaManager** (optional) — introspects database schema

New files needed: 4 (auth module, connection module, record parser, advanced options type).
Existing files to edit: 2 (factory registration + `ConnectionModuleConfig` enum).

## Step 1: Add Connection Type

In `connection/src/ConnectionModuleConfig.ts`:

```typescript
export enum ConnectionTypes {
  NEO4J = 1,
  POSTGRESQL = 2,
  YOUR_DB = 3, // Add here
}
```

## Step 2: Define Advanced Options

Each connector has its own advanced options type. Add yours in `connection/src/generalized/interfaces.ts`:

```typescript
export interface YourDbAdvancedOptions extends BaseAdvancedOptions {
  yourDbConnectionTimeout?: number;
  yourDbMaxPoolSize?: number;
}
```

Then add it to the union type:

```typescript
export type AdvancedConnectionOptions =
  | Neo4jAdvancedOptions
  | PostgresAdvancedOptions
  | YourDbAdvancedOptions;
```

## Step 3: Implement AuthenticationModule

Extend the abstract `AuthenticationModule`. The `createDriver()` method returns `unknown` — your subclass narrows to the concrete driver type.

```typescript
// connection/src/yourdb/YourDbAuthenticationModule.ts
import { AuthenticationModule } from "../generalized/AuthenticationModule";
import { AuthConfig, YourDbAdvancedOptions } from "../generalized/interfaces";

export class YourDbAuthenticationModule extends AuthenticationModule {
  private pool: YourDbPool;

  constructor(authConfig: AuthConfig, advancedOptions?: YourDbAdvancedOptions) {
    super();
    this._checkConfigurationConsistency(authConfig);
    this._validateUri(authConfig.uri, ["yourdb:"]);
    this.pool = this.createDriver();
  }

  createDriver(): YourDbPool {
    return new YourDbPool({
      host: this._authConfig.uri,
      user: this._authConfig.username,
      password: this._authConfig.password,
    });
  }

  async verifyAuthentication(): Promise<boolean> {
    // Test the connection
  }

  async updateAuthConfig(authConfig: AuthConfig): Promise<void> {
    // Recreate driver with new config
  }

  getPool(): YourDbPool {
    return this.pool;
  }

  async close(): Promise<void> {
    await this.pool.end();
  }
}
```

## Step 4: Implement ConnectionModule

Extend the abstract `ConnectionModule`. Wrap errors using `wrapError()` so consumers receive normalized `ConnectorError` instances.

```typescript
// connection/src/yourdb/YourDbConnectionModule.ts
import { ConnectionModule } from "../generalized/ConnectionModule";
import { wrapError, ConnectorErrorType } from "../generalized/ConnectorError";
import { QueryStatus } from "../generalized/interfaces";

export class YourDbConnectionModule extends ConnectionModule {
  authModule: YourDbAuthenticationModule;

  async runQuery(params, callbacks, config) {
    if (this.handleEmptyQuery(params.query, callbacks)) return;
    try {
      const result = await this.authModule.getPool().query(params.query);
      callbacks.onSuccess(result);
    } catch (error) {
      const wrapped = wrapError(error, "yourdb");
      callbacks.setStatus?.(
        wrapped.type === ConnectorErrorType.TIMEOUT
          ? QueryStatus.TIMED_OUT
          : QueryStatus.ERROR,
      );
      callbacks.onFail?.(wrapped);
    }
  }

  async checkConnection(config): Promise<boolean> {
    try {
      await this.authModule.getPool().query("SELECT 1");
      return true;
    } catch (error) {
      const wrapped = wrapError(error, "yourdb");
      console.warn("Connection check failed:", wrapped.type);
      return false;
    }
  }
}
```

> **Note:** You must also add a `detectYourDbErrorType()` function in `ConnectorError.ts` and update `wrapError()` to handle the new DB type.

## Step 5: Implement RecordParser

Extend `NeodashRecordParser` to transform raw query results into NeoBoard's tabular format.

## Step 6: Implement SchemaManager (optional)

Implement the `SchemaManager` interface for query editor autocomplete:

```typescript
import { SchemaManager } from "../schema/schema-manager";
import { DatabaseSchema } from "../schema/types";

export class YourDbSchemaManager implements SchemaManager {
  async fetchSchema(authConfig: AuthConfig): Promise<DatabaseSchema> {
    // Return tables, columns, etc.
  }
}
```

## Step 7: Register in Factory

In `connection/src/adapters/factory.ts`:

```typescript
case ConnectionTypes.YOUR_DB:
  return new YourDbConnectionModule(authConfig, advancedOptions);
```

## Step 8: Add Connection Form Fields

Update `component/src/components/composed/connection-form.tsx` to include UI fields specific to your database.

## Step 9: Write Tests

Use **Testcontainers** for integration tests:

```typescript
import { GenericContainer } from "testcontainers";

const container = await new GenericContainer("yourdb:latest")
  .withExposedPorts(5555)
  .start();
```
