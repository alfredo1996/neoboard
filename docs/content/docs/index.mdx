NeoBoard is a visual dashboarding tool for Neo4j and PostgreSQL databases. Build interactive dashboards, charts, and forms — all from your browser.

## What can you do?

- **Connect databases** — add Neo4j and PostgreSQL connections with encrypted credential storage
- **Build dashboards** — create multi-page dashboards with a drag-and-drop grid layout
- **Visualize data** — choose from bar, line, pie, table, graph, map, and more chart types
- **Add interactivity** — use parameter widgets (dropdowns, date pickers, sliders) to filter data across charts
- **Manage users** — invite team members with admin, creator, or reader roles
- **Export and share** — export dashboards as JSON and import them into other NeoBoard instances

## Get started in 5 minutes

Follow the [installation guide](/docs/getting-started/installation) to run NeoBoard locally, then the [quick start](/docs/getting-started/quick-start) to create your first dashboard.
