NeoBoard uses role-based access control to manage what each user can see and do. This guide covers user creation, roles, and the write permission toggle.

![Users management page](/screenshots/users.png)

## Roles

Every user is assigned one of three roles.

| Role | Dashboards | Connections | Users | Write Queries |
|------|-----------|-------------|-------|---------------|
| **Admin** | View, create, edit, delete | View, query and delete all tenant connections; edit own | Create and manage users | Yes, always (own connections only) |
| **Creator** | View, create, edit, delete own | Add; edit or delete own; use shared | No access | Yes, if enabled (own connections only) |
| **Reader** | View dashboards shared with them and public dashboards | Use shared connections (cannot add or modify) | No access | No |

- **Admin** has full access to dashboards, user management and settings, and can view, query and delete every connection in the tenant. Only a connection's owner can edit it.
- **Creator** can build and edit dashboards and widgets, add connections, and edit or delete the connections they own. Creators can also run queries against connections an admin has shared; only admins can share a connection or manage other users' connections.
- **Reader** can view dashboards shared with them and public dashboards, but cannot edit or create anything or manage connections. Readers can still run read-only queries: any query against a connection shared with the tenant, and on other connections only the queries in dashboards they can view. Keep sensitive databases on private connections if readers should not query them freely.

## Write Permission

The **write permission** toggle is an additional control, separate from the role. It controls write queries (e.g., `CREATE`, `INSERT`, `UPDATE`, `DELETE`) and most of the changes a Creator can make.

- The toggle applies only to **Creators**. **Admins** always have write permission and **Readers** never do; their switch is fixed and cannot be changed.
- When **enabled**, a Creator can run write queries through Form widgets on connections they own, and can create and change dashboards, widget templates and API keys.
- When **disabled**, a Creator can still view dashboards and run read-only widget queries, but cannot run write queries, create, edit, import, duplicate or delete dashboards, save widget templates, or create or revoke API keys. It does not stop them from adding or editing connections or managing sharing on dashboards they already own.

Write queries only run against connections the user owns, whatever their role.

## Creating a User

1. Navigate to **Users** in the sidebar.
2. Click **Create User**.
3. Fill in the user details:
   - **Name**: The user's display name
   - **Email**: Their login email address
   - **Password**: A strong initial password
   - **Role**: Select Admin, Creator, or Reader
4. Toggle **Write permission** on or off based on your needs.
5. Click **Create**.

The new user can now log in with their email and password.

## API Keys

For programmatic access to NeoBoard, you can generate API keys. Creating a key needs write permission.

![Settings page](/screenshots/settings.png)

1. Navigate to **Settings** in the sidebar.
2. Go to the **API Keys** section.
3. Click **Create API Key**.
4. Copy the key immediately. It will not be shown again.

Use the API key in the `Authorization` header when calling the NeoBoard REST API.
