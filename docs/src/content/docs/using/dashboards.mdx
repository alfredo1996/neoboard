Dashboards are the primary way to organize and display data in NeoBoard.

![Dashboard list](/screenshots/tour/dashboard-list.png)

## Creating a Dashboard

1. Click **Dashboards** in the sidebar
2. Click **New Dashboard**
3. Enter a name and optional description
4. Click **Create**

To edit, click the **Edit** button on any dashboard. To delete, open **Dashboard options** and select **Delete**.

## Structure

Each dashboard contains:

- **Name** and optional **description**
- One or more **pages**, each with its own set of widgets
- A **grid layout** (12-column responsive grid)
- **Settings** like auto-refresh interval

## Multi-Page Support

Dashboards can have multiple pages. Each page has independent widgets and layouts. Use pages to organize related views:

- Page 1: Overview metrics
- Page 2: Detailed analysis
- Page 3: Graph exploration

## Grid Layout

- **Drag** widgets to reposition them
- **Resize** by dragging widget edges
- Widgets added from the editor start at 4 columns by 3 rows; there is no minimum size, so you can resize one down to a single grid cell
- Layout is saved per page

## Permissions

| Role | View | Edit | Delete | Share |
|------|------|------|--------|-------|
| Admin | All | All | All | All |
| Creator | Own, shared and public | Own + shared (editor), when write permission is on | Own only, when write permission is on | Own only |
| Reader | Shared and public | No | No | No |

A widget can only use a connection you can query yourself: one you own, one an admin shared with the workspace, or, for an admin, any connection. The same applies when you duplicate or import a dashboard, so a dashboard shared with you that uses someone else's private connection cannot be duplicated. A connection already on a dashboard stays on it. Its owner and editors can write new queries on it, other than forms, while they have write permission and the dashboard's owner can use that connection. Otherwise, for example after an admin makes the connection private again or the owner is no longer an admin, its widgets keep running their saved queries, but only someone who can use the connection themselves can add new ones.

Anyone who can view a dashboard can submit its forms, whatever their role or write permission. Each submit runs the query saved with the form, on its saved connection and database. Adding a form, or changing a form's query, connection or database, needs access to that connection yourself, even when the dashboard already uses it: you own it, an admin shared it with the workspace, or you are an admin. A form left as saved stays, so an editor without that access can still move and resize it and edit the other widgets.

## Export and Import

Dashboards can be exported as JSON and imported into other NeoBoard instances. Admins can export any dashboard. Other users can export a dashboard only if they own every connection its widgets use. If a widget uses a shared connection or another user's connection, the export fails, even for users who can view the dashboard.

**What the export includes:**
- All widgets, queries, chart options, and layout
- Connection metadata (name, type) but **not credentials**
- Portable connection keys instead of internal IDs

**Example export format:**

```json
{
  "formatVersion": 1,
  "exportedAt": "2026-09-01T00:00:00.000Z",
  "dashboard": { "name": "Sales Overview", "description": null },
  "connections": {
    "conn_0": { "name": "Sales DB", "type": "postgresql" }
  },
  "layout": {
    "version": 2,
    "pages": [
      {
        "id": "p1",
        "title": "Page 1",
        "widgets": [
          {
            "id": "w1",
            "chartType": "bar",
            "connectionId": "conn_0",
            "query": "SELECT month, revenue FROM sales",
            "settings": { "title": "Revenue by Month" }
          }
        ],
        "gridLayout": [{ "i": "w1", "x": 0, "y": 0, "w": 6, "h": 4 }]
      }
    ]
  }
}
```

To import, click **Import Dashboard** on the dashboard list page and select a JSON file.
