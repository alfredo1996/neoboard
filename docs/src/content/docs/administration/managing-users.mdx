NeoBoard uses role-based access control to manage what each user can see and do. This guide covers user creation, roles, and the write permission toggle.

![Users management page](/screenshots/users.png)

## Roles

Every user is assigned one of three roles.

| Role | Dashboards | Connections | Users | Write Queries |
|------|-----------|-------------|-------|---------------|
| **Admin** | View, create, edit, delete | Manage all connections | Create and manage users | Yes (if enabled) |
| **Creator** | View, create, edit, delete own | View connections | No access | Yes (if enabled) |
| **Reader** | View only | No access | No access | No |

- **Admin** has full access to everything: dashboards, connections, user management, and settings.
- **Creator** can build and edit dashboards and widgets. Creators can run queries against connections but cannot add or modify connections.
- **Reader** can only view published dashboards. Readers cannot edit anything or run custom queries.

## Write Permission

The **write permission** toggle is an additional control, separate from the role. It determines whether a user can execute write queries (e.g., `CREATE`, `INSERT`, `UPDATE`, `DELETE`).

- When **enabled**, the user can run queries that modify data.
- When **disabled**, the user is restricted to read-only queries, regardless of their role.

This is useful when you want a Creator to build dashboards but not modify the underlying data.

## Creating a User

1. Navigate to **Users** in the sidebar.
2. Click **Create User**.
3. Fill in the user details:
   - **Name**: The user's display name
   - **Email**: Their login email address
   - **Password**: A strong initial password
   - **Role**: Select Admin, Creator, or Reader
4. Toggle **Write permission** on or off based on your needs.
5. Click **Create**.

The new user can now log in with their email and password.

## API Keys

For programmatic access to NeoBoard, you can generate API keys.

![Settings page](/screenshots/settings.png)

1. Navigate to **Settings** in the sidebar.
2. Go to the **API Keys** section.
3. Click **Create API Key**.
4. Copy the key immediately. It will not be shown again.

Use the API key in the `Authorization` header when calling the NeoBoard REST API.
