This guide walks through building a complete MongoDB connector plugin for NeoBoard. By the end, you will have an example plugin that lets users connect to MongoDB and run queries. [Creating a Connector Plugin](/extend/new-connector-plugin) has the full contract a connector must meet.

## Prerequisites

- Node.js 22+
- A NeoBoard instance running locally (`npm run dev`)
- A MongoDB instance (local or Atlas)

## 1. Scaffold the Plugin

Create a new directory in the connection package:

```bash
mkdir -p connection/src/mongodb
```

## 2. Implement the Connection Module

The connection module handles query execution. Create `connection/src/mongodb/MongoConnectionModule.ts`:

```ts
import {
  ConnectionModule,
  ConnectorError,
  ConnectorErrorType,
  QueryStatus,
  collectUpToLimit,
  determineQueryStatus,
  integerToRowValue,
  resolveQueryTimeout,
  type ConnectionConfig,
  type ConnectorConfig,
  type QueryCallback,
  type QueryParams,
  type RowValue,
} from "@neoboard/connector-sdk";
import {
  Decimal128,
  Long,
  MongoClient,
  MongoServerError,
  ObjectId,
} from "mongodb";

/**
 * One BSON value into the form NeoBoard's row value contract names — see
 * "What a row may hold" in Creating a Connector Plugin. A document crosses
 * JSON on its way to the browser, and nothing downstream knows it came from
 * MongoDB, so no driver class may survive: not at the top level, not nested.
 */
function toRowValue(value: unknown): RowValue {
  if (value === null || value === undefined) return null;
  if (value instanceof ObjectId) return value.toHexString();
  if (value instanceof Date) {
    return Number.isNaN(value.getTime()) ? null : value.toISOString();
  }
  // A 64-bit integer: a number when a double holds it exactly, else a string.
  if (value instanceof Long) return integerToRowValue(value.toBigInt());
  // Lossless decimal string, never a rounded double.
  if (value instanceof Decimal128) return value.toString();
  if (typeof value === "number") return Number.isFinite(value) ? value : null;
  if (Array.isArray(value)) return value.map(toRowValue);
  if (typeof value === "object") {
    return Object.fromEntries(
      Object.entries(value).map(([key, item]) => [key, toRowValue(item)]),
    );
  }
  return value as RowValue;
}

export class MongoConnectionModule extends ConnectionModule {
  authModule = null as any; // Satisfies abstract property; MongoDB uses client directly
  private client: MongoClient;
  private database: string;

  // ONE config bag: the values of the descriptor's fields, keyed by field.key.
  // Keys this connector did not declare may be present too; it ignores them.
  constructor(config: ConnectorConfig) {
    super();
    this.database = String(config.database);
    this.client = new MongoClient(String(config.uri));
  }

  async runQuery<T>(
    queryParams: QueryParams,
    callbacks: QueryCallback<T>,
    config: ConnectionConfig,
  ): Promise<void> {
    try {
      await this.client.connect();
      // A widget may override the connection's database for one query.
      const db = this.client.db(config.database ?? this.database);

      // Parse the query as a JSON command: { collection: "users", filter: {} }
      const command = JSON.parse(queryParams.query);
      const collection = db.collection(command.collection);

      // config.timeout is a per-query override and usually unset. This
      // connector declares no timeout field of its own, so unset means the
      // 30 s default — never "no bound".
      const timeout = resolveQueryTimeout(config.timeout);
      // maxTimeMS is enforced server-side
      const cursor = collection.find(command.filter ?? {}, { maxTimeMS: timeout });
      // MAX_ROWS+1: never a fixed row cap; keep config.rowLimit rows and detect one more
      const { rows: docs, truncated } = await collectUpToLimit(cursor, config.rowLimit);

      // The one pass over the documents: every value into its canonical form.
      // Stringifying `_id` alone left Dates, Longs, Decimal128s and nested
      // ObjectIds in the row as live driver objects.
      const rows = docs.map((doc) => toRowValue(doc));

      callbacks.setStatus?.(
        truncated
          ? QueryStatus.COMPLETE_TRUNCATED
          : determineQueryStatus(rows.length, config.rowLimit),
      );
      callbacks.onSuccess?.(rows as T);
    } catch (error) {
      if (error instanceof MongoServerError && error.code === 50) {
        // MaxTimeMSExpired
        callbacks.setStatus?.(QueryStatus.TIMED_OUT);
        callbacks.onFail?.(
          new ConnectorError(error.message, ConnectorErrorType.TIMEOUT, error),
        );
        return;
      }
      callbacks.onFail?.(error);
    }
  }

  async checkConnection(config?: ConnectionConfig): Promise<boolean> {
    try {
      await this.client.connect();
      await this.client.db(config?.database ?? this.database).command({ ping: 1 });
      return true;
    } catch {
      return false;
    }
  }

  async close(): Promise<void> {
    await this.client.close();
  }
}
```

## 3. Create the Descriptor and the Plugin

What the connector **is** goes in a descriptor: pure data, with no import of the `mongodb` driver, so it stays safe to bundle for a browser. Create `connection/src/mongodb/descriptor.ts`:

```ts
import type { ConnectorDescriptor } from "@neoboard/connector-sdk";

export const mongoDescriptor: ConnectorDescriptor = {
  type: "mongodb",
  label: "MongoDB",
  category: "database",
  queryLanguage: "json",
  // find() does not enforce config.accessMode "READ". Keep this false, or
  // enforce READ with a read-only database user or role.
  supportsWrite: false,
  supportsGraphData: false,
  fields: [
    {
      key: "uri",
      label: "Connection URI",
      type: "uri",
      group: "connection",
      required: true,
      placeholder: "mongodb://localhost:27017",
      protocols: ["mongodb:", "mongodb+srv:"],
    },
    {
      key: "database",
      label: "Database",
      type: "text",
      group: "connection",
      required: true,
      placeholder: "mydb",
    },
  ],
};
```

No username, no password: a connector declares what *it* needs, and nothing is mandatory for every connector.

The plugin is that descriptor plus the factory that needs the driver. Create `connection/src/mongodb/plugin.ts`:

```ts
import type { ConnectorPlugin } from "@neoboard/connector-sdk";
import { mongoDescriptor } from "./descriptor";
import { MongoConnectionModule } from "./MongoConnectionModule";

export const mongoPlugin: ConnectorPlugin = {
  ...mongoDescriptor,

  createModule(config) {
    return new MongoConnectionModule(config);
  },
};
```

## 4. Register the Plugin

Add it to the connector registry in `connection/src/connector-registry.ts`:

```ts
import { mongoPlugin } from "./mongodb/plugin";

// After existing registrations:
registry.register(mongoPlugin);
```

Or, for a plugin shipped as its own npm package: install it into the NeoBoard checkout (`npm install neoboard-connector-mongodb`), add `{ "package": "neoboard-connector-mongodb", "export": "mongoPlugin" }` to the `connectors` array in `neoboard-connectors.json` (omit `export` if the plugin is the package's default export; add `"overrides": true` only to replace a connector with the same `type`, since a duplicate type otherwise throws at startup), then run `npm run dev` or `npm run build`. Both run `scripts/generate-connector-imports.mjs`, which compiles the package into the registry. Connectors are not discovered at runtime. See [Creating a Connector Plugin](/extend/new-connector-plugin#8-load-it-into-neoboard).

## 5. Install the MongoDB Driver

```bash
npm install mongodb --workspace=connection
```

## 6. Test the Plugin

Create `connection/__tests__/mongodb/` with integration tests using Testcontainers:

```ts
import { MongoDBContainer } from "@testcontainers/mongodb";

describe("MongoDB connector", () => {
  let container;

  beforeAll(async () => {
    container = await new MongoDBContainer("mongo:7").start();
  });

  afterAll(async () => {
    await container.stop();
  });

  it("executes a find query", async () => {
    const module = mongoPlugin.createModule({
      uri: container.getConnectionString(),
      database: "test",
    });

    // Insert test data, then query
    // ...
  });
});
```

## 7. Use It

Once your connector is registered, the connection dialog still offers only Neo4j and PostgreSQL, so create the connection through `POST /api/connections` with `{ "name": "...", "type": "mongodb", "config": { "uri": "mongodb://host:27017", "database": "mydb", "username": "...", "password": "..." } }`. The API still requires a non-empty `username` and `password` for every connector type, whatever its descriptor declares, so pass placeholder values your module ignores.

After that, testing the connection, listing databases and running queries all use your module. Queries are JSON, for example `{ "collection": "users", "filter": { "age": { "$gt": 25 } } }`. For now the widget editor offers only the table chart for a non-built-in connector type, the query editor is plain text, and widget templates cannot target it.

## Publishing as an npm Package

To distribute your plugin:

1. Create a separate package: `neoboard-connector-mongodb`
2. Export the plugin definition
3. Users install with `npm install neoboard-connector-mongodb`
4. List it in their `neoboard-connectors.json` (with `"export": "mongoPlugin"` for a named export) and rebuild with `npm run build`

[Creating a Connector Plugin](/extend/new-connector-plugin#8-load-it-into-neoboard) also explains that a Docker image built with `npm ci` can include the connector only once the package is published to a registry.
