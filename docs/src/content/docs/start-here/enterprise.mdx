Unless a page says otherwise, these docs describe NeoBoard's community edition, the open-source edition you get from [Install NeoBoard](/start-here/install).

An enterprise edition is in development. It is not generally available, and this page makes no promise about features, prices or dates.

## Planned features

The enterprise edition is planned to add:

- **Single sign-on**: sign in through your organization's OIDC identity provider.
- **Custom roles**: roles beyond Admin, Creator and Reader.
- **Connector labels and aliases**: tag connections, and refer to one logical connection by the same name in every environment.
- **Environment selector**: switch a dashboard between environments, such as staging and production.
- **Bulk connection import**: add many connections at once.
- **Dashboard sharing links**: share a dashboard through a link.

## Trying single sign-on early

Single sign-on configuration is documented on the [Single Sign-On](/security/sso) page, for teams that want to try it early. It is not finished: that page notes what it does not do yet.

## Ask about the enterprise edition

To ask about the enterprise edition or early access, start a thread in [GitHub Discussions](https://github.com/alfredo1996/neoboard/discussions).
