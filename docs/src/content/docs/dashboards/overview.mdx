Dashboards are the primary way to organize and display data in NeoBoard.

![Dashboard list](/screenshots/dashboard-list.png)

## Creating a Dashboard

1. Click **Dashboards** in the sidebar
2. Click **New Dashboard**
3. Enter a name and optional description
4. Click **Create**

To edit, click the **Edit** button on any dashboard. To delete, open **Dashboard options** and select **Delete**.

## Structure

Each dashboard contains:

- **Name** and optional **description**
- One or more **pages**, each with its own set of widgets
- A **grid layout** (12-column responsive grid)
- **Settings** like auto-refresh interval

## Multi-Page Support

Dashboards can have multiple pages. Each page has independent widgets and layouts. Use pages to organize related views:

- Page 1: Overview metrics
- Page 2: Detailed analysis
- Page 3: Graph exploration

## Grid Layout

- **Drag** widgets to reposition them
- **Resize** by dragging widget edges
- Minimum size: 2 columns by 2 rows
- Layout is saved per page

## Permissions

| Role | View | Edit | Delete | Share |
|------|------|------|--------|-------|
| Admin | All | All | All | All |
| Creator | Own + shared | Own + shared (editor) | Own only | Own only |
| Reader | Shared only | No | No | No |

## Export and Import

Dashboards can be exported as JSON and imported into other NeoBoard instances.

**What the export includes:**
- All widgets, queries, chart options, and layout
- Connection metadata (name, type) but **not credentials**
- Portable connection keys instead of internal IDs

**Example export format:**

```json
{
  "name": "Sales Overview",
  "pages": [
    {
      "name": "Page 1",
      "widgets": [
        {
          "type": "bar",
          "title": "Revenue by Month",
          "connectionKey": "sales-db",
          "query": "SELECT month, revenue FROM sales",
          "layout": { "x": 0, "y": 0, "w": 6, "h": 4 }
        }
      ]
    }
  ],
  "connections": {
    "sales-db": { "name": "Sales DB", "type": "postgresql" }
  }
}
```

To import, click **Import Dashboard** on the dashboard list page and select a JSON file.
