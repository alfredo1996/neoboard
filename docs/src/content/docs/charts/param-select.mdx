## Overview

Parameter Select widgets collect user input and pass it to other widgets' queries as `$param_name` variables. They enable interactive filtering across an entire dashboard without modifying queries. Parameter widgets do not display data themselves.

## Parameter Types

| Type | Input Control | Value Produced |
|------|--------------|----------------|
| Select | Dropdown (populated by a seed query) | Single string |
| Multi-select | Dropdown with **Allow multiple selections** ticked | Array of strings |
| Freetext | Free-text input | String |
| Date | **Date Picker**, mode Single Date | ISO date string |
| Date Range | **Date Picker**, mode Date Range | `$param_<name>_from` and `$param_<name>_to` |
| Relative Date | **Date Picker**, mode Relative Date (Today, Last 7 days, ...) | `$param_<name>_from` and `$param_<name>_to` |
| Number Range | Dual-handle slider with a min, max and step | `$param_<name>_min` and `$param_<name>_max` |

## Seed Query (Select / Multiselect)

For Select and Multiselect types, a seed query populates the dropdown options. Return a single column -- each row becomes an option.

### Cypher

```cypher
MATCH (m:Movie)
RETURN DISTINCT m.released AS year
ORDER BY year
```

### SQL

```sql
SELECT DISTINCT role FROM "user" ORDER BY role
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| Placeholder | text | (empty) | Hint text shown when no value has been chosen |
| Search-as-you-type | boolean | true | Allow typing to filter the option list in real time |
| Default Value | text | (empty) | Value used on dashboard load when no selection has been made |
| Sync to URL | boolean | false | Persist the selected value as a URL parameter for sharing and page reloads |

## Using Parameters in Queries

Other widgets reference parameter values using `$param_name` syntax in their queries:

```cypher
MATCH (m:Movie)
WHERE m.released = $param_year
RETURN m.title, m.released
ORDER BY m.title
```

```sql
SELECT name, email FROM "user"
WHERE role = $param_role
ORDER BY name
```

## Tips

- Enable Sync to URL so users can bookmark or share a dashboard with specific filter values pre-selected.
- Set a Default Value for parameters that should always have a selection on first load.
- See [Parameters](/using/parameters) for details on parameter substitution, cascading parameters, and advanced usage.
