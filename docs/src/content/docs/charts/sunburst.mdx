## Overview

The Sunburst chart displays hierarchical data as concentric rings. Inner rings represent higher levels, outer rings represent leaves. It shares the same data format as Treemap and Circle Packing.

## Query Format

Return hierarchical data with `name` and `value` columns. A `parent` column turns flat rows into a tree.

The contract, in full:

- **Leaf rows are enough.** A name that appears only in the `parent` column is created for you — you do not need to return a row for each parent.
- **A parent's own value is the sum of its children**, unless you return a larger one explicitly. A parent value smaller than its children's total is ignored, because the children would overflow it.
- **Rows sharing a parent and a name are summed** into one node. The same name under two different parents stays two nodes.
- **Values must be positive numbers.** A row whose value is zero, negative, missing or non-numeric is skipped — it has no area to draw. Numeric strings are accepted.
- **Every column you return travels with the node**, so styling rules and click actions can use columns beyond `name` and `value`.
- If the `parent` links form a cycle, the widget says so instead of drawing a partial tree.

### Cypher

```cypher
MATCH (d:Department)-[:HAS_TEAM]->(t:Team)-[:HAS_MEMBER]->(m:Member)
RETURN d.name AS parent, t.name AS name, count(m) AS value
```

### SQL

```sql
SELECT region AS parent, country AS name, population AS value
FROM demographics
ORDER BY region, population DESC
```

## Options

| Option | Default | Description |
|--------|---------|-------------|
| Show Labels | `true` | Show segment name labels |
| Max Label Depth | `2` | Maximum ring depth for labels (0 = auto) |
| Sort | `desc` | Segment order: largest first, smallest first, or data order |
| Highlight on Hover | `true` | Emphasize segment and ancestors on hover |

## Features

- **Smart label management** — auto-hides labels on crowded rings (>12 segments)
- **Ancestor path on hover** — hover any segment to see its full path highlighted with bold labels
- **Click to drill down** — click a segment to make it the new root
- **Rule-based styling** — color segments by condition
- **Click actions** — click a segment to navigate or set a parameter
