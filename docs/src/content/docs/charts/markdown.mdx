## Overview

The Markdown widget renders static rich text content directly on the dashboard. Use it for headings, instructions, documentation links, or any explanatory text that helps users understand the dashboard. No query or database connection is required.

Text reads at 14px with real line spacing, and headings use the sans face (the serif is for page titles only). Code is set in IBM Plex Mono on a soft tint (light grey, or a step lighter than the card in dark mode), with keywords in azure and strings in green in both themes. Tables look like data tables: a quiet header and hairline rows. A text widget with no title shows no header band while you only view the dashboard with a mouse; in edit mode, and on a touch screen, the band stays so the controls remain reachable.

## Query Format

This widget does not use a query. Content is entered directly in the Chart Options panel.

## Options

| Option           | Type | Default | Description                                                                                          |
| ---------------- | ---- | ------- | ---------------------------------------------------------------------------------------------------- |
| Markdown Content | text | (empty) | Markdown text to render. Supports headings, bold, italic, links, lists, code blocks, and blockquotes |

## Supported Markdown Syntax

```markdown
# Heading 1

## Heading 2

### Heading 3

**Bold text** and _italic text_

- Bullet list item
- Another item

1. Numbered list
2. Second item

[Link text](https://example.com)

> Blockquote

`inline code` and code blocks with triple backticks
```

## Tips

- Use Markdown widgets as section headers to organize a dashboard into logical groups.
- Add a brief description at the top of a dashboard explaining what data sources it covers and how to interpret the charts.
- Markdown widgets resize with the grid layout, so keep content concise to avoid scrolling in small widgets.
