Widgets are the building blocks of dashboards. Each widget runs a query and displays the result as a chart, table, graph, or form.

## Widget Types

| Type | What it shows | Expected data |
|------|--------------|---------------|
| Bar Chart | Vertical or horizontal bars | Rows with a category column and a value column |
| Line Chart | Time series and trend lines | Rows with an x-axis column and one or more y-axis columns |
| Pie Chart | Proportional slices | Rows with a label column and a value column |
| Single Value | One large number (KPI) | A single row with one column |
| Table | Sortable, paginated data grid | Any tabular result |
| Graph | Nodes and relationships (Neo4j) | Graph data (nodes and edges) |
| Map | Geographic markers on a map | Rows with latitude and longitude columns |
| JSON Viewer | Collapsible JSON tree | Any query result |
| Form | Input fields that run a write query | User-defined form fields |

## How to Create a Widget

The widget editor walks you through five steps:

1. **Connection** — pick which database to query
2. **Query** — write a Cypher or SQL query
3. **Chart type** — choose how to visualize the result
4. **Options** — map columns, set colors, configure axes and labels
5. **Save** — the widget appears on your dashboard

Click **Run** at any point to preview the result before saving.

## Parameter Widgets

Parameter widgets collect user input and pass it to other widgets' queries. They do not display data themselves.

| Parameter type | Input control | Value produced |
|---------------|---------------|----------------|
| Select | Dropdown (populated by a seed query) | Single string |
| Text | Free-text input | String |
| Number | Numeric input | Number |
| Date | Date picker | ISO date string |
| Date Range | Start/end date pickers | `{start, end}` object |
| Boolean | Toggle switch | `true` or `false` |
| Multiselect | Multi-value dropdown | Array of strings |
| Slider | Range slider | Number |

Other widgets reference parameter values with `$param_name` in their queries. See [Parameters](/concepts/parameters) for details.
