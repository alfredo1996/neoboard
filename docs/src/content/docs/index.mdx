## What can you do?

- **Connect** to Neo4j and PostgreSQL databases
- **Build** dashboards with 12+ chart types (bar, line, pie, graph, map, table, and more)
- **Create** interactive parameter widgets that filter data across charts
- **Write** mutation queries with form widgets
- **Manage** users with role-based access (Admin, Creator, Reader)
- **Export** and import dashboards as JSON
