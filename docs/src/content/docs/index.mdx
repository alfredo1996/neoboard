## What is NeoBoard?

NeoBoard is an open-source dashboarding tool for hybrid database architectures. It connects to **Neo4j** and **PostgreSQL** databases, letting you build rich, interactive dashboards without writing frontend code -- 18 chart types, interactive parameters, form widgets that write back, multi-page dashboards, JSON export/import, role-based access, encrypted credentials and multi-tenancy. [What is NeoBoard](/start-here/what-is-neoboard/) has the full list and a map of these docs.

## Get Started

Choose the path that fits your setup:

| Method | Command | Best for |
|--------|---------|----------|
| **Setup script (recommended)** | `git clone` + `bash install.sh` | Trying NeoBoard out — installs deps, starts Docker, runs migrations |
| **Manual setup** | `npm install` + `neoboard env` + `npm run dev` | Contributors hacking on the source |
| **Production** | Docker Compose (recommended), a Node.js process under systemd, or Kubernetes | Real deployments |

See the [Install guide](/start-here/install/) for the first two, [Production deployment](/deploy/production/) for Docker Compose, and [Run from a build](/deploy/run-from-a-build/) for Node.js and Kubernetes.
